## Структура каталогов следующая:

### Web Frontend
Веб-интерфейс

### coraza-spoa - HAProxy SPOE Agent
**coraza-spoa/cmd** - Пакет входа, точка входа программы  
**coraza-spoa/internal** - Внутренние пакеты, отвечают за внутреннюю функциональность  
**coraza-spoa/internal/log_store** - Отвечает за хранение и обработку логов брандмауэра  
**coraza-spoa/internal/agent** - SPOE Agent  
**coraza-spoa/internal/application** - Обработчик SPOE Request/Response  
**coraza-spoa/pkg** - Внешние пакеты, могут вызываться другими модулями  
**coraza-spoa/pkg/server/agent_server** - Создание SPOE Agent, управление запуском, остановкой, перезагрузкой SPOE Agent

### pkg - Общие пакеты
Отвечают за инструменты, используемые несколькими модулями, могут использоваться другими модулями

**pkg/database/mongo** - Пакет базы данных, обработка операций с БД, унифицированная обертка для БД, шаблон Singleton. Connect - получение клиента БД, GetCollection - получение коллекции. Используется драйвер MongoDB v2: `go.mongodb.org/mongo-driver/v2/mongo`  
**pkg/utils** - Утилиты, инструменты которые могут использоваться несколькими модулями  
**pkg/model** - Слой моделей, отвечает за определение моделей данных, общие модели данных  
**pkg/model/blocked_ips.go** - Определение модели записей заблокированных IP, содержит IP-адрес, причину блокировки, URI запроса, время блокировки и другую информацию

### server - Backend
Отвечает за обработку backend API, управление запуском HAProxy, генерацию конфигураций, управление запуском HAProxy Coraza WAF SPOE (engine) и т.д.

Backend веб-сервис использует фреймворк Gin, gin-swagger и go-redoc для генерации документации API

**server/main.go** - Пакет входа, главная функция, содержит конфигурацию документации Swagger и Redoc  
**server/config** - Файлы конфигурации  
**server/model** - Слой моделей, отвечает за определение моделей данных  
**server/model/response.go** - Определение унифицированной модели API ответов  
**server/model/user.go** - Определение модели пользователя, содержит систему ролей  
**server/model/role.go** - Определение модели ролей и разрешений, поддерживает RBAC контроль доступа  
**server/model/site.go** - Определение модели сайта, содержит конфигурацию сайта, сертификаты, backend серверы и другую информацию

**server/dto** - Слой DTO, отвечает за определение объектов передачи данных, например модели данных запросов и ответов  
**server/dto/auth.go** - Определение модели данных запроса аутентификации  
**server/dto/site.go** - Определение модели данных запроса и ответа для сайтов  
**server/dto/config.go** - Определение DTO для управления конфигурацией, содержит модели запросов и ответов для инкрементного обновления конфигурации  
**server/dto/blocked_ip.go** - Определение DTO для управления заблокированными IP, содержит модели запросов с пагинацией, ответов и статистической информации

**server/controller** - Контроллеры, слой управления в MVC  
**server/controller/auth.go** - Контроллер аутентификации, обрабатывает вход, регистрацию, сброс пароля и управление пользователями  
**server/controller/site.go** - Контроллер сайтов, обрабатывает CRUD операции с сайтами  
**server/controller/config.go** - Контроллер конфигурации, обрабатывает получение и обновление системной конфигурации, поддерживает режим инкрементного обновления  
**server/controller/blocked_ip.go** - Контроллер заблокированных IP, обрабатывает постраничные запросы, получение статистики и очистку устаревших записей

**server/service** - Слой сервисов, отвечает за бизнес-логику  
**server/service/auth.go** - Сервис аутентификации, обрабатывает логику аутентификации пользователей, сброса пароля и управления пользователями  
**server/service/site.go** - Сервис сайтов, обрабатывает бизнес-логику сайтов  
**server/service/config.go** - Сервис конфигурации, обрабатывает бизнес-логику системной конфигурации, поддерживает инкрементное обновление  
**server/service/blocked_ip.go** - Сервис заблокированных IP, обрабатывает бизнес-логику заблокированных IP, включая постраничные запросы, статистический анализ и очистку данных  
**server/service/daemon** - Слой демонов, отвечает за управление демонами, например демон HAProxy, демон Coraza WAF SPOE (engine) и т.д.  
**server/service/engine** - Слой движков, отвечает за управление движками, например управление движком Coraza WAF SPOE (engine)  
**server/service/haproxy** - Отвечает за управление запуском HAProxy, генерацию конфигураций и т.д.  
**server/service/daemon/runner** - Отвечает за управление демонами, например демон HAProxy, демон Coraza WAF SPOE (engine) и т.д.

**server/router** - Слой маршрутизации, отвечает за определение маршрутов  
**server/router/router.go** - Определение маршрутов, контроль доступа на основе RBAC, организация маршрутов по функциональным модулям

**server/repository** - Слой репозиториев, отвечает за операции с базой данных  
**server/repository/user.go** - Репозиторий пользователей, обрабатывает доступ к данным пользователей, включает создание начального пользователя  
**server/repository/role.go** - Репозиторий ролей, обрабатывает доступ к данным ролей, включает инициализацию ролей по умолчанию  
**server/repository/site.go** - Репозиторий сайтов, обрабатывает CRUD операции с данными сайтов  
**server/repository/waf_log.go** - Репозиторий логов WAF, обрабатывает запросы и агрегацию логов атак WAF  
**server/repository/config.go** - Репозиторий конфигурации, обрабатывает операции с системной конфигурацией в БД, поддерживает инкрементное обновление  
**server/repository/blocked_ip.go** - Репозиторий заблокированных IP, обрабатывает операции с записями заблокированных IP в БД, включая постраничные запросы, статистическую агрегацию и очистку устаревших данных

**server/middleware** - Слой middleware, отвечает за обработку промежуточного ПО, например обработка логов, аутентификация JWT, унифицированная обработка ошибок и т.д.  
**server/middleware/auth.go** - Middleware аутентификации JWT, включает контроль доступа на основе разрешений

**server/utils** - Утилиты, отвечает за определение классов инструментов  
**server/utils/response** - Пакет утилит ответов, предоставляет унифицированную обработку API ответов  
**server/utils/jwt** - Пакет утилит JWT, обрабатывает генерацию и проверку токенов, включает информацию о ролях и разрешениях пользователей

**server/validator** - Слой валидаторов, отвечает за обработку валидации, например валидация структур, валидация параметров запроса и т.д.  
**server/validator/validators.go** - Определение валидаторов, содержит функции регистрации валидаторов и унифицированную функцию инициализации  
**server/validator/struct_validators.go** - Определение валидаторов структур, содержит функции регистрации валидаторов структур и унифицированную функцию инициализации

**server/pkg** - Внешние пакеты, могут вызываться другими модулями

**server/service/waf_log.go** - Сервис логов WAF, предоставляет бизнес-логику для запросов и агрегации логов WAF

**server/controller/waf_log.go** - Контроллер логов WAF, обрабатывает HTTP запросы для запросов и агрегации логов WAF

**server/dto/waf_log.go** - DTO логов WAF, содержит определение параметров запроса и формата ответа
