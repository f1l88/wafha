# 🧩 Техническая документация фронтенд-проекта (React + Vite + TailwindCSS + TypeScript)

## 📚 Технологический стек проекта

* **Фреймворк:** React + Vite + TypeScript
* **Стилизация:** TailwindCSS
* **UI-библиотека:** shadcn/ui
* **Иконки:** lucide-react
* **Маршрутизация:** `react-router` версии ^7.1.3
* **Менеджер пакетов:** pnpm

### 🧱 Структура макета

* Левая часть — **Sidebar** (основная навигация)
* Правая часть — **область контента**

  * В верхней части контентной области расположен **Breadcrumb** (хлебные крошки)
  * Для каждого раздела sidebar отображается свой путь breadcrumb

---

## 📋 Требования к проекту

1. Полноценная структура и функциональность, чистый и поддерживаемый код
2. Именование каталогов и файлов должно соответствовать стандартам, важные участки кода снабжены комментариями
3. Разработка и сборка выполняются с помощью **Vite**
4. Используется **TailwindCSS** для разработки стилей
5. Используется **shadcn/ui** для компонентов интерфейса
6. Используется **react-router v7.1.3** для маршрутизации
7. Используется **@tanstack/react-query@5.69.0** для работы с данными
8. Используется **TanStack Table** для таблиц
9. Состояние управляется через **Zustand**
10. Формы разрабатываются с использованием **react-hook-form**
11. Валидация выполняется с помощью **zod**
12. Поддерживается **интернационализация (i18n)** с помощью **react-i18next**
13. Доступны **русский и английский языки**, по умолчанию используется русский
14. Загрузка переводов — через **i18next-http-backend**
15. Определение языка пользователя — через **i18next-browser-languagedetector**
16. Для иконок используется **lucide-react**

# 🧠 Security Dashboard (панель безопасности)

## Обзор проекта

Реализована панель безопасности WAF — визуальная система мониторинга на основе React и TypeScript.

## Технологический стек

* React 18 + TypeScript
* shadcn/ui
* TanStack Query
* react-hook-form + zod
* echarts
* react-i18next
* TailwindCSS

## Основные функции

1. **Реальное время** — обновление каждые 5 секунд
2. **3D-глобус** — визуализация атак
3. **Статистика** — количество блокировок, атакующих IP, обращений
4. **Список атак** — последние веб-атаки
5. **График QPS** — запросы в секунду
6. **Мультиязычность** — русский / английский
7. **Полноэкранный режим**

## Структура модуля

```
src/feature/security-dashboard/
├── hooks/
│   └── useSecurityDashboard.ts
├── component/
│   ├── SecurityDashboardLayout.tsx
│   ├── StatCard.tsx
│   ├── AttackIPList.tsx
│   ├── RealtimeAttackList.tsx
│   ├── DashboardQPSChart.tsx
└── index.ts
```

## Основные компоненты

* **useSecurityDashboard** — загрузка данных, фильтрация, автообновление каждые 5 секунд
* **SecurityDashboardLayout** — макет панели (верх, низ, бок, центр)
* **StatCard** — карточка статистики (числа, иконки, эффекты)
* **AttackIPList** — список атакующих IP с геоданными
* **RealtimeAttackList** — поток атак в реальном времени
* **DashboardQPSChart** — график QPS на echarts

## Дизайн

* Основной цвет: `#a071da`
* Фон: тёмный градиент
* Карточки: полупрозрачный фон с эффектом «матового стекла»
* Мягкие тени и плавные переходы

## Источники данных

* useOverviewStats('24h') — статистика за 24 часа
* useAttackEvents — список атак
* useRealtimeQPS(120) — данные QPS

## Интернационализация

* Поддержка русского и английского языков
* Геолокации отображаются в зависимости от языка

## Оптимизация и производительность

* useMemo для вычислений
* Защита от утечек памяти при опросе
* Оптимизация рендеринга графиков

## Развёртывание

* Путь страницы: `/monitor/security-dashboard`
* Поддерживается hot reload
